TRIPLE R AUDIO - VISUAL GUIDE

1. Quick Windows Setup (mmsys.cpl)

  1. Click Open Sounds in the Triple R Audio app.
  2. Right-click Hi-Fi Cable Input (or Art Tune) → Configure Speakers → Select 7.1 Surround.
  3. Right-click → Properties → Advanced → Select 24-bit, 48000 Hz (Studio Quality).
  4. In the Enhancements tab, check Loudness Equalization → click Settings → set Release Time to Short (2).

2. Using with Elgato Wave Link 3.0

  • In Wave Link 3.0, add Hi-Fi Cable Output as an input channel.
  • Set Wave Link Monitor Mix to your physical headphones/DAC.
  • Use the TUNE: ON/OFF button in Triple R Audio to toggle between competitive tuning and clean normal audio anytime!
